## 핵심 검증 가설 — 이 실험의 존재 이유

**네이버가 자기 서비스로 채운 SERP에 외부 도메인이 들어갈 수 있는가.**

`족저근막염 깔창` 1면 구성 (2026-07-31 `/api/judge` 실측):

```
in.naver.com(인플루언서) 100% · cafe.naver.com 100% · tv.naver.com(영상) 66.7%
blog.naver.com 33.3% · natical.shop 33.3%
```

judge 는 이를 전부 `noise` 로 분류해 **✅ "권위 인컴번트 없음"** 판정을 냈다. 판정 자체는 규칙대로다 — 나무위키·지식백과·정부기관 같은 권위 도메인이 없다.

**그런데 우리는 blog.naver.com 이 아니라 외부 도메인(blog.dimad.kr)이다.** judge 의 bucket 분류에는 "네이버 자체 서비스는 외부 도메인에게 벽으로 작동하는가"라는 축이 없다. 인플루언서·동영상 슬롯이 많다는 건 네이버가 이 쿼리에 자사 서비스를 밀어넣고 있다는 뜻이고, 그만큼 외부 도메인 자리가 줄어든다.

- **이 가설이 참이면** → judge ✅ 중에서도 `in.naver`·`tv.naver` 비중이 높은 후보는 별도 감점이 필요하다. 판정 룰 개정 대상
- **거짓이면** → 네이버 UGC 점유는 오히려 기회 신호다(권위 문서가 없다는 뜻이므로). 지금 룰 유지

대조군이 같은 날 발행분 안에 있다. `밸롭 지압슬리퍼` 1면은 rank1 `blog.naver`·rank2 `cafe.naver` 로 **일반 블로그 비중이 높다**. 두 글의 노출 발생 속도가 갈리면 위 가설의 방향이 잡힌다.

## 부수 검증 축

1. **후기가 점유한 자리를 "판단 구조"로 뚫을 수 있는가** — 두 글 모두 감상 대신 분기표·수치로 설계했다. 특히 깔창 글은 236명 RCT(기성품 95% > 맞춤 68%), 오즈비 표(발목 유연성 23.3배 > BMI 5.6배)처럼 개인 후기가 구조적으로 만들 수 없는 데이터를 전면에 뒀다
2. **브랜드 중립 글의 수익성** — 깔창 글은 쿠팡 링크를 의도적으로 넣지 않았다(중립성이 유일한 무기라서). 애드센스만으로 어느 정도 나오는지가 "제품 링크 없는 정보글"의 수익 표본이 된다
3. **계절 타이밍** — `족저근막염 깔창` 검색 트렌드는 9월 피크(최고 100 / 최저 53). 7월 말 발행이 피크 전 색인 안정에 유리하다는 가정. 심평원 집계도 매년 3분기 환자 증가와 일치
4. **오타 키워드 처리** — 추천기가 준 `족적근막염슬리퍼`(1,880)는 오타 변형이었고 정타 `족저근막염 슬리퍼` 는 29,670으로 **15배**였다. 정타는 질병관리청 rank2 로 ⛔ 였지만, **오타 키워드를 받으면 정타를 analyze 로 확인하는 절차**가 이 건에서 처음 필요해졌다
