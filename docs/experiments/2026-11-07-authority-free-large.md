## 왜 하는가

1. **10-24 히트 분석에서 가장 크게 갈린 변수**가 "1면에 권위 출처(공공기관·위키·전문기관)가 있느냐"였다 — 있음 18% / 없음 59%, 여기에 월검색 5,000↑ 를 더하면 **69%** (표본 40편, 사후) → [`research/2026-10-24-hit-analysis.md`](../research/2026-10-24-hit-analysis.md) 가설 후보 A
2. **11-07 사전 확인 — 곡선 모양(에버그린 vs 급등)은 히트를 가르지 못했다.** 02~08월 발행 히트 46편 vs 비히트 40편의 대표 키워드 12개월 곡선: 에버그린(중앙÷최대 ≥ 0.4) 비중 **69% vs 66%**. 급등형 중 매년 돌아오는 계절형(호랑이콩·플럼바고·선풍기 날개)은 히트, 한 번뿐인 이벤트형(니파바이러스·두쫀볼·희망저축계좌)은 전원 0. 에버그린인데 0 인 글(치매 초기증상 등)은 권위 출처가 1면을 차지할 주제다
3. **10-29 급등 이후 큰 자리의 옛 글이 올라왔다** — `cuckoo-service-center-location`(문서 27,433) 노출 164 → 8,444. 큰 검색량 자리를 시험하기에 지금이 가장 유리하다
4. 사용자 문제 제기(11-07): **급등 키워드는 식는다 → 묵혀도 되는 자리를 보자.** 이벤트형 배제로 반영한다

## 가설 (H12)

> **1면 상위 5개에 권위 출처가 없고, 월검색 5,000 이상, 문서 10,000 미만이며, 한 번뿐인 이벤트형이 아닌 자리에 쓰면 히트 확률이 기저율보다 확실히 높다**

| 조건 | 기준 |
|---|---|
| 권위 출처 없음 | `/api/domains` rank1~5 에 `.go.kr` · `.or.kr` · `.ac.kr` · 나무위키 · 위키백과 · 지식백과(terms.naver) · 식약처 · health.kr · hira · kdca · 대학병원 **없음** |
| 검색량 | 월 **5,000 이상** |
| 문서수 | **10,000 미만** (10-24: 문서 10,000↑ 히트 0/34) |
| 이벤트형 배제 | 12개월 곡선 중앙값 ÷ 최댓값 **≥ 0.2** (계절형은 허용) |
| 쓰지 않는 것 | judge 단독 판정 · harvest · 형태 판정 · 급등 여부 |
