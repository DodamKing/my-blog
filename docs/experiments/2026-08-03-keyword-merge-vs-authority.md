## 가설 A — 진입확률 vs 기대클릭 (이번의 본 실험)

발행 하한 산식(`기대클릭 = 검색량 × 문서수 구간 전환율`)은 **1면에 들었을 때의 값**이다. 진입 확률이 곱해져 있지 않다. 두 글은 이 축의 양 극단이다.

| | 예초기 | 헤라 |
|---|---|---|
| 주 키워드 | 예초기 줄날 교체법 (1,650) | 헤라 썬크림 (17,260) |
| 문서수 | **20** | **9,447** |
| 기대클릭(주 키워드) | 495 | **2,589** |
| 1면 구조 | 인컴번트 0, blog·cafe·kin 전부 UGC | 공식몰·아모레몰·인플루언서 블로그 |
| 노출광고수 | 4~7 | **8** (광고CTR 2.69% = 상업 의도 강함) |
| 성격 | 레딜형 정보 진공 | 브랜드 head, 우리 권위 0 |

**예측**: 예초기가 헤라보다 **먼저, 더 높은 순위로** 잡힌다. 기대클릭 절대값은 헤라가 5배지만, 신생 도메인이 문서 9,447건짜리 브랜드 head 1면에 드는 것은 별개 문제다.

**판정 기준 (데이터 보기 전에 먼저 고정)**

- 예초기 노출 ≥ 100 & 헤라 노출 < 50 → **가설 A 지지.** 문서수가 진입확률의 지배 변수. 앞으로 head 키워드는 기대클릭이 커도 후순위로 미룬다
- 둘 다 노출 → 병합 전략과 무관하게 양쪽 다 유효. 하한 산식을 그대로 신뢰
- 헤라만 노출 → **가설 A 기각.** "권위 0이라 head 는 못 뚫는다"는 우리 통념이 틀린 것. 문서수 기반 회피를 재검토
- 둘 다 무노출 → 병합 전략 자체(가설 B)를 의심한다

⚠️ 2026-07-31 스냅샷 반성 반영: 최근 세 스냅샷 결론이 전부 "방향은 위, 스케일은 목표의 1/160"으로 같았다. **결과를 보고 해석하지 말 것.** 위 임계값을 그대로 적용한다.

## 가설 B — 키워드 병합(흡수)의 부분매칭 수율

여러 검색어를 별도 글로 쪼개지 않고 1편에 흡수했다. 07-29 염색약(답이 다른 롱테일 흡수)과 달리, 이번은 **제목에 정타로 박히지 못한 서브 키워드가 부분매칭으로 얼마나 걸리는가**가 쟁점이다.

| 글 | 주 키워드(제목 정타) | 흡수된 서브 키워드 | 흡수 검색량 |
|---|---|---|---|
| 예초기 | 예초기 줄날 교체법 (1,650) | 날 교체법 1,440 · 줄통 2,510 · 줄날통 1,210 · 꼬마대장 1,720 · 오성 380 | 7,260 |
| 헤라 | 헤라 썬크림 (17,260) + **헤라톤업선크림 8,500 도 제목 정타** | 헤라유브이프로텍터 2,090 | 2,090 |

- 쪼갰다면 예초기는 3편(합계 기대클릭 1,304)이 됐겠지만, `날 교체법`과 `줄날 교체법`은 **제목이 3글자 차이라 유사중복 위험**이 실재했다. 병합 시 기대치를 600~800으로 낮춰 잡았다
- 헤라는 제목에 **두 검색어를 정타로 박았다**(`헤라 썬크림` + `헤라톤업선크림` 붙여쓰기 그대로). 병합글에서 정타 2개가 동시에 걸리는지가 관측 포인트

**판정 기준**: 8/17 스냅샷 키워드 목록에 **주 키워드 외 서브 키워드가 1개라도 잡히면 병합 유효**. 하나도 없이 주 키워드만 잡히면 → 부분매칭 수율이 0에 가깝다는 뜻이므로, 앞으로는 흡수 대신 분할하되 **제목 어휘를 충분히 벌린다**로 룰 개정.

## 부수 관측 축

1. **시즌 타이밍의 방향이 반대다.** 예초기는 벌초 성수기(9월) **직전**이라 색인 시간을 확보했고, 헤라는 자외선 피크 **한복판**이라 색인이 늦으면 시즌을 지나친다. 같은 날 발행이지만 유효 관측 창이 다르다 — 예초기는 9월까지 연장
2. **판정과 의도 게이트의 분리.** `예초기 줄통`은 judge ✅(인컴번트 0)였으나 `buckets` rank2가 lotteon.com 이었다. 단독 발행이면 우리 의도 게이트에 걸려 탈락할 자리다. **judge 는 "인컴번트가 있는가"만 보고 "쇼핑 SERP인가"는 안 본다**는 것을 처음 명시적으로 확인 — 상세는 `../research-backlog.md`
3. **조사 노트가 스스로 모순 없이 틀릴 수 있다.** 초안이 꼬마대장을 "4도날 계열"로 단정했는데 조사 노트에 근거가 없었고, 실제 유통품은 3도날이었다. 검토(04)도 못 잡았다 — **조사 노트 내부에서는 모순이 없어 쿠팡 상품명과 대조해야만 보였다.** 사용자가 발행 후 발견해 수정(관절형 안전날 + 3도/4도 설명 추가). 안전이 걸린 주제에서 이 유형의 오류를 어떻게 앞당겨 잡을지가 과제
