## 이번 스냅샷에서 기각된 가설

### 1. 도구 페이지 확대 — 기각했다가 **재고 필요**로 되돌림

TOP30 전체에서 `/tools/` URL은 jeonse **하나뿐**. 도구 9개 중 8개가 월 3클릭 미만.

→ 최초 판정은 "도구 형식은 볼륨을 만들지 못한다" 기각. **그러나 외부 사례 조사에서 뒤집혔다** — 계산기는 폴더 안에서 1개 페이지가 전체의 **25~85%** 를 가져가는 것이 정상 패턴이다(Bankrate 25.9%, NerdWallet 33.7%, americanpregnancy 85.4%). 우리 분포는 실패 패턴이 아니라 교과서적 패턴이다.

**남은 진짜 문제는 "도구가 안 된다"가 아니라 "우리 도구 하나가 CTR 0.2%"다.**

**CTR을 고치려는 작업이 CTR을 반토막냈다.** 새 title이 실측 검색어를 물긴 물었으나(TOP30 키워드에 "전세대출 월납입금"·"이자비용 계산" 존재) 동시에 훨씬 넓은 쿼리에 걸려 희석됐다.

**되돌리지 않는다** — 손실은 월 7클릭인데 노출 13,150짜리 유일한 볼륨 자산을 또 흔드는 것은 기대값이 나쁘다. redill이 "건드려 망가짐 → 되돌려도 안 돌아옴"의 전례다.

### 3. 발행 하한 산식 — **신뢰 불가 판정**

전환율 표(30%/15%/6%)의 출처를 추적하면 07-24 스냅샷 TOP10에서 뽑은 **표본 5건, 실질 URL 4개**다. 그리고:

- **5건 전원의 월검색량이 5~120 사이다.** 이 표를 `쿠쿠서비스센터`(105,700)에 적용하는 것은 최대 표본의 **2,114배 외삽**이다
- **5건 전부 1면에 이미 든 승자다.** 못 든 글은 한 행도 없다 — 종속변수로 표본을 선별한 생존 편향
- **노출 ≈ 검색량이다**(실측 비율 0.84~1.43). 따라서 "전환율"은 사실 **1면에 든 페이지의 CTR을 옮겨 적은 값**이고, 진입 확률이 곱해져 있지 않다

07-19~08-04 발행 19편 대조: **기대클릭 합 54,069 vs 실측 최대 57.**
⚠️ 색인 지연이 실측 8주(`fan-blade-removal` 5/28 발행 → 7/24 첫 등장)라 이 표만으로 기각할 수는 없다. 기각 근거는 다음이다 — `워싱소다` 한 편의 예측 14,966을 채우려면 노출 99,770이 필요한데 **계산기 제외 사이트 전체 노출이 15,850**이다.

**편당 300을 넘긴 글은 역대 1편**(`redill-zero-purchase-guide` 827, 2026-05)뿐이고 그것은 트렌드 스파이크였다가 편집 사고로 무너졌다. **2위 기록이 91이다.**

### 4. "하한 300이 발행을 걸렀다" — 사실이 아님

하한 신설(07-30) 이후 컷된 9건 중 **6건이 H2 섹션으로 본문에 그대로 들어갔다.** 편수를 줄인 것은 07-31 신설 **상한(2편)**이었다. 하한은 필터가 아니라 "이 키워드를 제목에 박을까"만 정하는 정렬 함수로 작동했다.

지난 2주 실제로 후보를 소멸시킨 게이트는 **쇼핑 SERP·권위 인컴번트 둘뿐**이다(포카리 시드 / 예초기 브랜드축 6개 / 이동식에어컨·감자 축).

### 이 데이터가 뒤집은 것

**1. 우리 RPM은 문제가 아니다.** $3.31은 외부 조사의 한국어 실측 중앙값 **$2.87보다 높다**(Q1 $1.7 / Q3 $4.7). 즉 "같은 PV에서 8~15배 벌어지는 편차"에서 **우리는 위쪽 절반에 있다.**

→ **수익화 구조를 고쳐서 얻을 배율이 작다는 뜻이고, 트래픽이 진짜 병목인 것이 확정됐다.** 확인하지 않았다면 존재하지 않는 레버(수익 효율 개선)를 90일간 팠을 것이다.

**2. 목표까지의 배율이 200배 → 70배로 줄었다.** 월 $4.3 → $300.

**3. 광고 슬롯은 이미 꽉 찼다.** 페이지당 5.74개. 광고를 늘려 RPM을 올릴 여지가 없다.

**4. RPM $3.31을 만든 것은 단가가 아니라 CTR이다.**
- CTR **2.37%** — 높은 편
- 클릭당 **$0.024** — 매우 낮다. 리서치의 한국 평균 AdSense CPC $0.10의 **1/4**이고, 비교 사례(정책·복지 블로그)의 클릭당 $0.06보다도 낮다

→ 우리 주제(건강보조제·염색약·선풍기·전자담배)가 **광고주 입찰이 약한 영역**이다. 외부 조사상 주제 교체로 확인되는 실측 배율은 2.5~3배.

**5. Journey by Mediavine 문턱 미달.** 요건 월 1,000 **세션**인데 PV가 1,290이고 세션은 그보다 적다(검색 클릭 기준 약 520). 애드센스 외 유일하게 열려 있던 네트워크 경로도 지금은 닫혀 있다.

**6. Active View 63%** — 업계 양호선 70%+ 대비 낮다. 개선 여지는 있으나 배율은 1.1배 수준.
