# 외부 리서치 — 우리 밖에서는 어떻게 노출하고 어떻게 버는가 (2026-08-05)

⚠️ **이 문서는 프로젝트 최초의 외부 근거 문서다.** 그 전까지 모든 판단이 우리 자체 데이터(표본 5~30건)에서 나왔고, 그 결과가 자기 강화 편향으로 흘렀다. 독립 리서처 4명이 웹 검색으로 조사했고, **우리 데이터를 근거로 쓰지 말 것**을 지시했다.

**읽는 법**: 여기 수치를 판정 기준으로 박지 말 것. 과거에 구글 CTR 통설을 네이버에 옮겼다가 실측에서 뒤집힌 전례가 있다. **빌려올 수 있는 것은 "구조와 선택지"이고, 빌려오면 안 되는 것은 "임계값"이다.**

## 1. 네이버 — 외부 도메인이 들어갈 자리는 하나뿐

### 블록별 진입 가능 여부

에어서치 개편 이후 통합검색은 스마트블록 중심으로 재편됐고, VIEW 탭은 블로그/카페 탭으로 분해됐다.

| 블록 | 소재 | 외부 도메인 |
|---|---|---|
| 파워링크 | 검색광고 입찰 | 가능 (유료) |
| 플레이스 | 네이버 플레이스 DB | 불가 |
| 인기글 / 스마트블록 / 함께 찾은 콘텐츠 | 블로그·카페·포스트 | **불가** |
| 내또래 | 블로그·쇼핑·지식iN | 불가 |
| AI 추천 블록 | 블로그·뉴스·지식백과 | 뉴스 매체 한정 |
| 인플루언서 | 네이버 인플루언서 등록자 | **불가** |
| 지식iN / 쇼핑 / 이미지 / 동영상 | 네이버 자산 | 불가 |
| **웹사이트(웹문서)** | 외부 크롤링 | **가능 — 유일한 오가닉 자리** |

영문 업계 서술도 동일: *"Only the Websites section contains external (non-Naver) domains."*

### 2019년 말 정책 변경 — 우리 상황의 직접 배경

외부 블로그(워드프레스·티스토리)가 **블로그 탭에서 밀려나 웹사이트 탭으로 이동**했다. 1차 실측 2건:

| 운영자 | 결과 |
|---|---|
| 워드프레스 정보꾸러미 | 블로그 섹션 시절 **일 400~500명** → 웹사이트 섹션 이후 **일 100명 미만, 네이버 비중 3% 미만** |
| Twinword | 오가닉 트래픽 중 **구글 92% / 네이버 8%**. *"웹문서 섹션은 블로그 섹션에 비해 거의 모든 키워드에서 낮은 순위"* |

⚠️ **표본 2건, 둘 다 워드프레스 기술 블로그.** 일반화 근거로는 약하다. 그리고 **실패 사례만 수치와 함께 공개되고 성공 사례는 수치가 없다**는 문헌 비대칭 자체가 표본 편향일 수 있다.

### 랭킹 축이 다르다 — C-Rank는 우리에게 적용되지 않는다

- **C-Rank / D.I.A / D.I.A+ 는 네이버 UGC(블로그) 전용 지표**다. 웹문서 영역에도 적용된다는 네이버 공식 문서를 찾지 못했다(부재 증거이지 반증은 아님)
- 외부 도메인의 축은 **2023-11-16 웹사이트 검색 공신력 업데이트**다. 네이버 설명: "수백 개 랭킹 시그널" 중 ③ **웹문서 출처 사이트의 특징**이 포함
- 공개된 우대 예시: 기업 실적 → **상장사 IR·증권사** / 지역 정보 → **지자체·공공기관**
- **개인 블로그가 이 축에서 어디에 위치하는지는 공개 자료에 없다**

## 2. 성공·실패 사례 — 기준선

### 「The Great Blogging Collapse」 (2026) — 생존 편향이 교정된 유일한 자료

2022년에 "6자리 수익 블로거"로 소개된 **100개를 사전 고정 코호트로 잡고** 4년 뒤 재측정.

| 지표 | 값 |
|---|---:|
| 오가닉 트래픽 변화 **중앙값** | **-85%** |
| 80% 이상 상실 | 55개 |
| 오가닉 0 도달 | 12개 |
| 여전히 성장 | 21개 |

니치별 중앙값: **육아 +108% / 음식 -44% / 패션 -95% / 금융 -99%**

살아남은 쪽은 1차 경험 기반(직접 촬영한 레시피, 직접 뜬 뜨개 패턴). ⚠️ 단 **HouseFresh는 수 주간 실물 테스트를 하고도 -91%** 였고, 그 원인은 콘텐츠가 아니라 SERP 구성 변화(쇼핑 리스팅 64개+, 스폰서, Quora)로 기술됐다. **1차 경험은 충분조건이 아니다.**

### 트래픽 분포 — 96.55%는 정상이다

| 데이터 | 값 | 표본 |
|---|---|---|
| **구글 트래픽 0인 페이지** | **96.55%** | Ahrefs 140억 페이지 |
| 백링크 0 페이지가 월 1,000+ 달성 | **1/6,671** | 2,000만 페이지 |
| 블로그 유입 중 검색 비중 | 60.68% (건강·의료 **87.85%**) | SimilarWeb 32.5억 방문 |

⚠️ Ahrefs 본인이 표본 편향(품질 콘텐츠 쪽 치우침)을 인정 — 96.55%는 과대 추정일 수 있다.
⚠️ **개인 블로그 코호트의 페이지별 클릭 분포를 집계한 공개 연구는 존재하지 않는다.** "상위 10편이 87%를 먹는 게 정상인가"를 판별할 기준선이 공개 영역에 없다.

### 대량 발행의 성적 — 양방향 기록이 공존

| 방향 | 근거 |
|---|---|
| 통함 | Lim How Wei: 월 6편 이하 5개월 5,439PV → 월 20~25편 5개월 **72,849PV** (자기보고+캡처) |
| 통함 | Orbit Media 설문 808명: 발행 빈도 높을수록 "강한 결과" 보고 비율 높음 ⚠️ 자기평가, 역인과 배제 불가 |
| 실패 | Jake Ward "SEO Heist": AI로 1,800페이지 → 월 49만 방문 → **3주 만에 11.6만** |
| 실패 | Great Blogging Collapse: **발행 편수와 무관하게** 요약 가능한 정보성 콘텐츠는 붕괴 |

**구글 정책 문언은 "AI인지"가 아니라 "양산인지"를 기준으로 쓰여 있다** — `scaled content abuse`는 자동/수동/혼합을 구분하지 않는다고 명시(2024-03).

⚠️ 널리 인용되는 Originality.ai "디인덱스 사이트의 100%에서 AI 흔적" 연구는 **AI 탐지기 판매사의 자체 연구**다. 표본 선정·오탐률 미공개.

### 계산기·도구 — 우리 도구 가설을 뒤집은 자료

| 사이트 | 단일 계산기 페이지 비중 |
|---|---|
| americanpregnancy.org | 상위 폴더의 **85.4%** |
| NerdWallet | 계산기 21개 중 1개가 **33.7%** |
| Bankrate | 1,065페이지 폴더에서 1페이지가 **25.9%** |

## 3. 구글 색인 — 82건 미크롤의 정체

### 두 상태의 결정적 차이

```
Discovered(발견됨-미크롤) = 구글이 URL을 알지만 "가져오지 않기로" 결정 → 콘텐츠를 본 적 없음
Crawled(크롤링됨-미색인)  = 가져와 읽었지만 "넣지 않기로" 결정      → 보고 거절
```

**Discovered 상태의 결정은 페이지 내용에 근거할 수 없다.** 구글이 그 파일을 연 적이 없기 때문이다. 남는 근거는 **도메인 수준 신호 + URL 패턴 + 내부 링크 위치**뿐이다.

### 크롤 예산은 적용된다 — 단 용량이 아니라 수요

구글 공식 크롤 예산 문서의 적용 대상 3번째 항목:

> **"Search Console에서 총 URL 중 상당 비중이 Discovered – currently not indexed 로 분류되는 사이트"**

**여기엔 페이지 수 조건이 없다.** 흔히 인용되는 "소규모 사이트는 크롤 예산 신경 쓸 필요 없다"는 요약이 이 조건을 빠뜨린 것이다.

| 축 | 정적 사이트 적용 |
|---|---|
| Crawl **capacity** limit (서버 용량) | 사실상 무제한 — **병목 아님** |
| Crawl **demand** (size, update frequency, **page quality**, relevance, popularity) | **여기가 병목** |

→ **크롤 예산은 맞지만 "지출 의사"의 문제다.**

### 구글의 공식 발언들

- **Mueller (2025-07)**: *"it's barely getting indexed, often that's a sign that our systems aren't convinced about the site overall"*
- **Mueller & Splitt**: *"if our systems are seriously worried about the quality of the website that they will reduce the number of pages at the index"* / **"It's not that you need to fix this technical issue"**
- **Marie Haynes (2026-04, Search Central 토론토)**: 색인될 콘텐츠는 **"personal experience"** 또는 **"knowledge no one else has"** 중 하나를 제공해야 한다. 걸러지는 유형은 *"쓰레기는 아니지만 이미 존재하는 걸 유능하게 재진술하는"* 콘텐츠
- **2025-05 이후 색인 자체가 좁아지는 추세** — Mueller: *"We don't index all content, and what we index can change over time"*

### 내부링크 처방 — 근거가 가장 약한 영역

⚠️ **먼저: 이미 Discovered 상태면 "발견"은 이미 성공했다.** 사이트맵이 작동 중이므로 내부링크가 작용할 수 있는 경로는 **발견이 아니라 우선순위 신호** 하나뿐이다.

**유일한 통제 실험 (SearchPilot SEO A/B)**

| 개입 | 결과 |
|---|---|
| 홈 푸터 내부링크 확장 | 대상 페이지 **+5%** |
| 인근 지역 상호링크 (약 8,000 지역 페이지) | 수신 페이지 **+7%** |
| **관련 글 링크 증가** | 제공 페이지 상승, **수신 페이지 null** |
| 링크 블록 내 링크 수 **축소** | 남은 링크 대상 **순위 상승** |

- 세 번째 줄이 블로그에서 가장 흔한 개입 형태다. **null이 나왔다**
- 네 번째 줄은 **링크 희석이 실재함**을 뜻한다 — 미색인 다수에 무차별 링크는 기존 상위 페이지 신호를 깎을 수 있다
- ⚠️ **결정적 한계: 이 실험들은 전부 트래픽을 측정했지 색인 여부를 측정하지 않았다.** "내부링크 → 색인" 인과를 직접 측정한 통제 실험은 조사 범위에 없다

**인용 금지로 분류된 주장**: "내부링크를 5~10개로 늘리면 색인이 60~80% 빨라진다"(원 출처·표본 추적 불가), Link Whisper 크롤 깊이 사례(수치·기간 전무, 자사 도구 마케팅)

### 페이지네이션 noindex — 우리에게 실재하는 후보

- **구글 공식 페이지네이션 가이드는 noindex를 권장한 적이 없다.** 각 페이지에 **자기 참조 canonical**을 권한다. `rel=next/prev`는 폐기됨
- **robots meta 문서**: `noindex` 단독은 링크 발견을 허용 (`nofollow`를 명시하지 않으면 링크를 따라감)
- **그러나 Mueller**: *"If we see the noindex there for longer then we think this page REALLY doesn't want to be used in search so we will remove it completely"* — 그리고 그 페이지의 링크도 더 이상 따라가지 않게 된다. **장기적으로 `noindex, follow` ≈ `noindex, nofollow`**
- **Sitebulb**은 이 상태("noindex,follow로만 도달 가능한 고립 URL")를 **High priority** 로 분류

두 입장은 시간 지평이 다를 뿐 둘 다 맞다 — noindex 페이지는 색인에서 빠져 재방문 이유가 줄고, 크롤이 뜸해지면 그 페이지의 링크도 사실상 죽는다.

### 🔍 선행 진단 (개입보다 먼저 할 것)

**Discovered 82건의 슬러그를 발행일 역순 목록에서의 위치와 대조한다.**

| 관측 | 결론 | 개입 효과 확률 |
|---|---|---:|
| 82건이 **목록 2페이지 이후**에 몰림 | 페이지네이션 noindex가 살아있는 원인 | **50~65%** |
| 82건이 **최신 글에도 고르게 분포** | 도메인 수준 크롤 수요 문제 | **15~25%** |

**측정 시점**: 0~2주 무변화는 정보가 아님 / 2~6주 첫 신호 / **8~12주가 적정 판정 시점** / 12주+ 무변화면 시나리오 B 확정.

### 색인 앞당기는 수단 — 실효성

| 수단 | 구글 효과 |
|---|---|
| **IndexNow** | **0.** 2021년 "테스트하겠다" 성명 이후 채택 없음. Bing·Yandex·**Naver**·Seznam·Yep만 지원 |
| Indexing API | **사용 불가** — JobPosting / BroadcastEvent 전용 |

| `lastmod` 갱신 | ⚠️ **역효과 위험** — 구글은 *"consistently and verifiably accurate"* 할 때만 사용. 색인 유도용 일괄 수정은 필드 자체를 불신하게 만든다 |
| URL 검사 수동 요청 | 하루 10~12건. 실측: 미색인 33,930건 제출 시 **29.37%만 색인** |

**수동 요청의 올바른 용도**: 82건을 밀어넣는 수단이 아니라, **소수를 강제 크롤시켜 "우선순위 문제인가 품질 문제인가"를 판별하는 실험 장치.**

### 색인률 벤치마크와 "색인되면 트래픽이 온다"

- Mueller (2021): "100페이지 중 80개가 색인되면 문제로 보지 않는다" ⚠️ 캐주얼 발언, 2021년 기준
- IndexCheckr 1,600만 페이지: 30일 내 64.86% / 3개월 76.81% / 6개월 93.2% ⚠️ **색인 모니터링 도구 사용자 = 색인 문제를 겪는 사이트로 표본 편향**
- **판정: "낮은 쪽"이다.** 단정할 근거는 없고, 2025~26년 색인 축소 추세로 현실 기준선은 인용 수치보다 낮아졌을 가능성

**⚠️ 그리고 색인 ≠ 트래픽이다.** Ahrefs 96.55% 무트래픽이 전부 **색인된 페이지**다. 게다가 미색인 집합은 무작위 표본이 아니라 **구글이 "유용할 확률"을 예측해 걸러낸 하위 꼬리**이고, 그 예측 신호는 트래픽이 안 오는 이유와 상당 부분 같다. **"미색인 건수 × 평균 글 트래픽"은 과대추정이다.**

## 4. 수익 구조 — 목표 역산 검증

### RPM $3 가정은 실측 중앙값과 일치한다

한국어 사례 **30건 역산 RPM**: 중앙값 **$2.87** / Q1 $1.7 / Q3 $4.7
(정렬: 0.20, 0.67, 0.79, 0.84, 0.87, 0.94, 1.14, 1.33, 1.64, 1.67, 1.74, 2.15, 2.17, 2.75, 2.80, 2.93, 3.13, 3.20, 3.31, 3.86, 4.30, 4.63, 5.00, 5.00, 5.93, 5.99, 7.69, 12.0, 17, 98)

여기서 나오는 필요 트래픽 **약 104,000**은 목표 10만과 일치하고, 실측 $300 달성 사례 범위(**39,000~180,000 방문**)도 10만을 중앙에 둔다.

**→ 역산의 산술과 스케일 감각은 실측과 모순되지 않는다.**

### 그러나 세 방향으로 틀릴 수 있다

**(a) 단위 불일치 — 과소추정 위험**
30건 중 **29건이 "방문자" 기준**이다. PV 기준으로 인증한 유일한 사례의 페이지 RPM은 **$0.84~$2.17**. 우리 역산이 PV 기준이면 **필요량은 15만 이상**일 수 있다.

**(b) $3의 출처가 실은 한국 실측이 아니다**
추적하면 **미국 기준 카테고리 RPM표**로 수렴한다(한 계산기 사이트가 *"카테고리별 미국 기준 RPM을 기본값으로 제공"*이라 자백). 한국 CPC/CPM 집계는 미국 대비 **4~6배 낮다**(한국 CPC $0.10 vs 미국 $0.61). 실측 중앙값이 $2.87인 것은 광고 개수·배치가 이 격차를 상쇄하고 있음을 시사하나 **판정할 데이터가 없다.**

**(c) 분산이 중앙값보다 크다 — 가장 실질적인 문제**

| 구간 | 실측 편차 |
|---|---|
| 일 300명 | $0.88/일 · $0.4/일 · **$0.06/일** → **15배** |
| 일 1,000~1,500명 | 월 44만원 · 16.2만원 · **5만원** → **8배** |
| **주제 교체 (여행→금융)** | **2.5~3배** |

**같은 PV 안의 편차가 주제 간 격차보다 크다.**

> **역산에서 가장 취약한 항은 RPM $3이 아니라 "PV가 유일한 변수"라는 구조다.**
> 수익을 가른 것은 PV가 아니라 같은 PV에서 8~15배를 만든 무언가였고, 그것을 특정한 공개 데이터는 존재하지 않는다.
> 힌트 하나 — 스포츠 블로그 kimta 실측: **"상위 10개 포스팅이 월 수익의 90%"**

### "고단가 니치 표"는 산술적으로 불가능하다

| 검증 | 값 |
|---|---:|
| 미국 GDN 실측 CPM — Finance & Banking | **$4.42** |
| 미국 GDN 실측 CPM — Healthcare / Technology | $3.78 / $3.20 |
| 애드센스 퍼블리셔 배분율 | **68%** |
| → 광고 RPM 상한 | **$3.0** (페이지당 광고 3개 다 채워야 $9) |

그런데 "Finance RPM $30~60"이 널리 유통된다. **나올 수 없다.** 같은 "금융" 카테고리에 4,000원 / 10,000~30,000원 / $10 / $25가 동시에 돈다.

**통설과 반대인 실측도 있다**: "연예·스포츠 300~800원"이라는 통설 vs 스포츠 블로그 kimta 실측 RPM **$3.13~3.20(약 4,400원)** — 통설의 5배.

### 밴드를 벗어난 유일한 축은 주제가 아니라 언어·지역

| 실측 | 값 |
|---|---|
| wplaybook 영문 페이지 | 페이지 RPM **$13.73** (단, 같은 블로그 4개월 집계는 $1.57 — 단일 일자 비교) |
| thewordcracker | **국내 방문자 가치 = 미국의 약 15%** (국내 방문 23배인데 수익 3.3배) |
| ariaddne2 (자기보고) | 한글 CPC 50~200원 / 영문 500~3,000원 |

### 쿠팡 파트너스 — 배율이 아니다

공식 가이드 원문 확인:

| 항목 | 공식 |
|---|---|
| 수수료 | **거래액 3%** (카테고리 요율표가 공식 문서에 **없다** — "뷰티3%/생활2%/가전1%" 표는 출처 미확인) |
| 쿠키 | 24시간 |
| 취소·반품 | **전액 차감** |
| 실효 실측 | 월 거래액 400만원+ → 정산 8만원 미만 = **2% 미만** |

**등가: 쿠팡 3만원 상품 1건(900원) = 애드센스 약 600PV.** 같은 자릿수다.

⚠️ **건강 카테고리 규제**: 공식 가이드가 **의료기기·조제유류의 체험/사용 후기 광고를 의료기기법상 금지 광고**로 지목한다. 건강기능식품도 별도 규제 대상. 경제적 이해관계 문구 미표기 시 **수익금 지급 중단 + 서비스 해지**.

### 구매의도 vs 정보성 — 방향은 공식, 크기는 미공개

쿠팡 공식 가이드 36p: 대표성 키워드(`자전거추천`)는 조회수↑·체류시간↓·**전환율↓**, 세부 키워드(`입문형 로드자전거 50만원`)는 반대. **단 배수는 공식·실측 통틀어 없다.**

### 광고 네트워크 교체 — 거의 막혀 있다

| 네트워크 | 요건 | 한국 트래픽 가부 |
|---|---|---|
| Raptive | 월 25,000 PV | ⛔ **트래픽 50%가 US·UK·CA·NZ·AU여야 함** (명시적 지역 게이트) |
| Ezoic | **월 250,000 활성 사용자** (2026-02~ 신규) | ⛔ 규모 |
| Mediavine 본망 | 연 광고수익 $5,000+ | ⛔ 규모. 단 **영어 사이트 요건 없음**이 공식 명시 |
| **Journey by Mediavine** | **월 1,000 세션, 지역 요건 없음** | **문턱상 유일하게 접근 가능** (평균 RPM $11.15 — 미국 트래픽 기준) |
| Monumetric | 월 10,000 PV + $99 셋업비 | 지역 요건 미공개 |

⚠️ **"Mediavine 50% Tier-1 규정"은 공식 문서에서 확인되지 않았다** — 심사 후기 기반 미검증 통설.
⚠️ **한국 트래픽 사이트가 애드센스를 떠나 RPM이 올랐다는 실측 0건.** 못 올린다는 반증도 없는 **데이터 부재** 상태.
⚠️ 메커니즘상 헤더비딩은 **한 임프레션의 입찰자 수를 늘리는 장치**이지 입찰자를 만들지 못한다. 어느 네트워크도 지역 열위를 기술로 상쇄한다고 주장하지 않는다.

### 트래픽 없이 수익을 만드는 축 — 등가 PV 환산

애드센스 RPM 1,500원 기준:

| 수익원 | 건당 | **애드센스 등가 PV** |
|---|---:|---:|
| 쿠팡 3만원 상품 1건 | 900원 | 600 |
| 텐핑 CPS 1건 | 434~2,174원 | 290~1,450 |
| **전자책 1권** (29,000원, 크몽 20% 수수료) | 23,162원 | **15,400** |
| 텐핑 참여형 CPA 1건 | 7,500~86,667원 | 5,000~57,800 |
| **보험·분양 리드 CPA 1건** | 50,000원+ | **33,000** |

**월 10,000 PV에서 전자책 1권 또는 CPA 리드 1건이 나오면 그 트래픽의 애드센스 수익 전액을 넘는다.**

⚠️ **그러나 이 경로들의 트래픽 대비 전환율 한국 실측이 전부 0건이다.** 배율 계산의 유일한 미지수가 전환율이고, 하필 그 값의 공개 데이터가 가장 비어 있다.
⚠️ CPA 국내 플랫폼은 로그인 후에만 단가 노출, 검색 가능 영역 상당수가 텔레그램 기반 불법 DB 매매.
⚠️ 네이버 프리미엄콘텐츠: 2023-10 기준 채널 1,645개 중 **342개(21%)가 그 해 신규 글 0건**.

### 인증 신뢰도

| 등급 | 결과 |
|---|---|
| **제3자 검증** | **0건.** 애널리틱스 공유 링크·정산서 원본 공개 사례 없음 |
| 스크린샷 있음 | 약 10건 |
| 자기보고 숫자만 | 나머지 대부분 |
| **판매 목적** | 강의·전자책 링크가 붙은 것 전부. 한 사이트는 본문에서 *"강의를 팔려고 하는 것도 사실"* 이라 자인 |

한 인증자 본인의 지적: **"브라우저 개발자도구로 10초면 조작 가능."** 그리고 "구글 광고비 100만원 지출 → 방문자 증가 → 애드센스 수익 발생" 식의 **광고비로 부풀린 인증** 패턴도 보고된다.

### 월 1만 PV 미만 × 월 $300 — 검증 가능한 한국어 사례 0건

$300+ 도달 사례의 최소 관측은 **월 39,000 방문(일 1,300명)**. 고액 주장(월 750만원, $7,800)은 **예외 없이 PV를 공개하지 않는다.**

⚠️ 이는 "불가능하다"의 근거가 아니라 **"그런 사례가 공개적으로 인증되지 않는다"**의 근거다 — 애드센스 외 수익원은 인증 문화 자체가 없다.

## 5. 조사 전체의 한계

1. **생존 편향** — "월 10만 PV 달성 후기"는 달성한 사람만 쓴다. 이를 부분 교정하는 자료는 Great Blogging Collapse 하나뿐
2. **벤더 이해상충** — AI 디인덱스 연구(탐지기 판매사), 콘텐츠 프루닝 사례(SEO 에이전시 자사 마케팅), 애드센스 RPM 가이드(강의 판매)
3. **한국 데이터 구조적 부재** — 편당 트래픽 분포를 공개한 한국 사례 0건. 한국어 애드센스 RPM 1차 통계 없음. Ezoic·Mediavine 공개 국가별 데이터에 **한국 자체가 없다**
4. **웹검색 한도 소진** — 4개 조사 모두 200회 한도에 걸림. 뽐뿌·클리앙 일부·Reddit·아이보스는 커버리지 얕음
5. **네이버 핵심 실측이 2018~2020년**
