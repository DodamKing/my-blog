## 가설

### 가설 A — 🔴 "고객센터"와 "서비스센터"는 다른 검색이다

기존 글이 **전화번호** 의도를 잡고 있는데, 같은 브랜드로 **방문 위치** 글을 하나 더 쓰는 게 자기잠식인가 아닌가. 근거는 **지역명 롱테일 9개**(청주 1,910 / 울산 1,650 / 대전 1,590 / 대구 1,450 / 부산 1,020 / 광주 900 / 울산 800 / 창원 630 / 대구 730)가 전부 좌표를 찾는 검색이라는 것.

- 지역 롱테일은 **별도 글로 쪼개지 않고 허브 글의 H3 섹션으로 흡수**했다. 답 구조가 같은 롱테일을 9편으로 나누면 유사중복 감점이고, 합계 1만 vs 허브 10만이라 나눌 이유도 없다
- 검증 대상: 두 글이 서로를 잠식하지 않고 **각자의 의도로 노출되는가**. 잠식이면 기존 글 노출이 떨어진다

#### ⭐ 가설 A-2 — 지역 분할 vs 흡수, 어느 쪽이 맞나 (이번 배치의 최대 미결)

사용자 관찰: **이 영역에서 잘하는 블로거들은 지역마다 글을 다 나눠서 쓴다.** 우리는 반대로 한 글에 흡수했다. 즉 이번 발행은 업계 관행과 정반대 베팅이다.

| | 분할 (경쟁자 방식) | 흡수 (우리 선택) |
|---|---|---|
| 지역 롱테일 커버 | 각 글이 지역명을 제목에 박아 정확히 매칭 | 허브 제목에 지역명 없음 — H3 텍스트로만 |
| 유사중복 위험 | 높음 (답 구조가 같음) | 없음 |
| C-Rank 주제 집중도 | 분산 | 집중 |
| 편당 제작비 | 9편 | 1편 |

- **분할이 맞다면**: 8/11에 허브가 `쿠쿠서비스센터`(105,700)로는 노출되는데 **지역 롱테일에서 노출이 거의 안 잡힐** 것이다. 제목에 지역명이 없어서 매칭이 약하기 때문
- **흡수가 맞다면**: 지역 검색어에서도 허브가 걸리고, 편당 1편으로 9편치를 먹는다
- **판정 방법**: 서치 어드바이저 키워드 리포트에서 **`{지역명} 쿠쿠서비스센터` 형태 검색어의 노출 유무**를 본다. 노출이 0에 가까우면 흡수 전략이 진 것이고, 그때 **상위 3개 지역(청주 1,910 / 울산 1,650 / 대전 1,590)만 분할 발행**해 재검증한다
- ⚠️ **지금 결론 내지 말 것.** 경쟁자가 그렇게 한다는 게 그 방식이 옳다는 증명은 아니다(양산형 제휴 사이트가 페이지를 늘리는 이유는 SEO가 아니라 광고 슬롯일 수 있다). 반대로 우리 흡수 판단도 아직 근거가 룰(유사중복 회피)뿐이고 실측이 없다. **8/11 데이터로 가른다**

### 가설 B — 🟡 실측 함정이 검색 가치가 되는가 (`cuckoo-service-center-location`)

공식 조회를 직접 돌려 나온 것들:
- **"광주"로 조회하면 0건** — 드롭다운에 광주 항목이 없고 "전남광주통합특별시"에 묶여 있다
- **공식 목록에도 "방문불가" 센터가 있다**(부산진구점)
- **센터 이름과 실제 주소가 다르다**(부산남구점→수영구, 서울 강서직영점→양천구)
- **취급구분 5종 중 '쿠쿠스토어'만 방문 수리 대상**
- SERP 1면의 `cuckoo-servicecenter.com`이 하단에 스스로 "공식 사이트가 아니며 팬 페이지"라고 명시

→ 1면 경쟁자(공식몰·소형 제휴사이트)가 절대 안 쓰는 내용이다. **직접 조회해봐야 나오는 정보가 실제로 순위를 만드는지** 검증한다.

### 가설 C — 🟢 문서 25건짜리 초저볼륨이 실제로 뚫리는가 (`cuckoo-water-purifier-cold-water-lukewarm`)

월검색 490 / 문서 **25건** / 신선도 갭 90%. 1면 1위가 지식인, 2위 카페 — **질문만 있고 정리된 답이 없다.** 이 블로그에서 문서수가 이렇게 적은 키워드를 잡은 적이 없다.

핵심 앵글은 **"정상 범위가 4~10℃로 6도나 벌어져 있어 위쪽 끝이면 미지근하게 느껴진다"** — 즉 상당수 호소가 고장이 아니다. 부가로 **"냉각수를 보충하면 95% 해결된다"는 인터넷 주장을 정면 반박**(공식 설명서에 그런 절차가 없고 냉각 계통은 밀폐계)했고, **정수 필터 교체와 냉수 온도는 무관**하다는 구분도 넣었다.

- 검증 대상: 검색량 490이 **클릭으로 환산될 가치가 있는가**. 절대 클릭이 1차 지표
