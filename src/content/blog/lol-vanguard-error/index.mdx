라이엇 뱅가드는 리그 오브 레전드와 함께 작동하는 라이엇 게임즈의 안티치트 프로그램입니다. 클라이언트와 커널 모드 드라이버로 이루어져 있고, 보통은 Windows가 부팅될 때 함께 시작됩니다. 게임을 켜기 전에 뱅가드가 PC 상태를 확인하는데, 이 단계에서 문제가 생기면 롤 뱅가드 오류가 뜨고 게임이 실행되지 않습니다.

가장 흔한 코드는 **VAN 84** 입니다. 대부분은 라이엇이 안내하는 순서대로 하면 풀리지만, 다른 보안 프로그램이 뱅가드를 방해하면 재설치만으로는 풀리지 않을 수 있습니다.

**3줄 요약**
- **VAN 84** → Windows 업데이트·재부팅 → vgc 자동 시작 → 뱅가드 제거 후 재설치 → 클린 부팅 순서로 시도
- **재설치해도 안 되면** → 라이엇이 VAN 83 문서에서 원인 후보로 직접 적은 Fasoo(파수) 소프트웨어가 깔려 있는지 확인
- **파수 DRM이 제거되지 않으면** → 복구 환경 명령 프롬프트에서 드라이버 이름을 바꿔 해결한 사례가 있음

## 롤 뱅가드 오류 VAN 84가 뜻하는 것

라이엇 고객지원의 공식 설명은 이렇습니다.

> 라이엇 뱅가드가 PC가 게임을 실행할 준비가 되었는지 확인하지 못했거나, 초기화 중 문제가 발생했음을 의미합니다.

라이엇의 VAN 84 안내문은 원인이 되는 프로그램 이름을 따로 적지 않고 "백그라운드 앱이나 서비스"라고만 표현합니다.

---

## 먼저 해볼 것 — 라이엇 안내 순서

아래는 라이엇이 VAN 84 문서에서 안내하는 순서입니다. 위에서부터 하나씩 해보고, 해결되면 거기서 멈추면 됩니다.

### 1. Windows 업데이트 설치 후 재부팅

설정의 Windows 업데이트에서 대기 중인 업데이트를 모두 설치한 뒤 PC를 다시 시작합니다.

### 2. vgc 서비스를 자동 시작으로 설정

뱅가드 서비스 이름은 **vgc** 입니다. 사전 검사(Pre-Check)를 쓰지 않는 PC라면 이 서비스를 자동으로 시작되게 해두라는 것이 라이엇 안내입니다.

1. `Win + R` 을 눌러 `services.msc` 입력
2. 목록에서 **vgc** 를 더블클릭
3. 시작 유형을 **자동** 으로 변경
4. 서비스 상태가 중지라면 **시작** 클릭
5. 적용 → 확인 → PC 재시작

재시작 후에는 Windows가 부팅될 때마다 뱅가드가 자동으로 시작됩니다.

### 3. 뱅가드 제거 후 재설치

- 시스템 트레이의 뱅가드 아이콘 → 고급 → **뱅가드 삭제**
- 또는 Windows 설정의 앱 목록에서 **Riot Vanguard** 제거

재부팅한 뒤 트레이에 뱅가드 아이콘이 없으면 제거된 것입니다. 라이엇 클라이언트나 게임을 실행하면 재설치가 자동으로 진행됩니다.

관리자 권한 명령 프롬프트에서 서비스를 직접 지우는 수동 제거 방법도 라이엇이 안내합니다.

```
sc delete vgc
sc delete vgk
```

실행 후 재부팅하고 `C:\Program Files\Riot Vanguard` 폴더를 삭제한 다음 게임을 실행해 다시 설치합니다.

### 4. 클린 부팅으로 방해 프로그램 확인

백그라운드 앱이나 서비스가 뱅가드를 방해하는지 클린 부팅 상태에서 확인합니다. 이 상태에서 게임이 실행된다면 평소 켜져 있는 다른 프로그램 중 하나가 원인입니다.

이후 순서로 라이엇은 게임 재설치, 네트워크 점검, 그래도 안 되면 로그 파일을 첨부한 고객지원 티켓 제출을 안내합니다.

### 사전 검사(Pre-Check)와 Windows 10

Pre-Check를 켜면 뱅가드가 Windows 시작 때 실행되지 않고, 라이엇 게임을 켤 때 시작됐다가 게임이 끝나면 종료됩니다. 다만 쓸 수 있는 조건이 까다롭습니다.

- Windows 11 버전 25H2 이상
- 보안 부팅
- TPM 2.0
- IOMMU
- VBS(가상화 기반 보안)
- HVCI(하이퍼바이저로 보호된 코드 무결성)

첫 조건 때문에 **Windows 10 PC에서는 Pre-Check를 쓸 수 없습니다.** Windows 10이라면 위 2번의 vgc 자동 시작 설정이 필요합니다. 사용 가능 여부와 보안 상태는 트레이의 VGTray에서 볼 수 있습니다.

## 자주 보는 다른 VAN 코드

- **VAN 9001** — TPM 2.0이 활성화된 상태로 감지되지 않는다는 뜻입니다. TPM 2.0을 켠 뒤 게임을 다시 실행합니다.
- **VAN 9003** — 보안 부팅이 켜져 있지 않다는 뜻입니다. UEFI/BIOS에서 보안 부팅을 켜고 저장한 뒤 재부팅합니다. 메뉴 이름은 메인보드 제조사마다 다릅니다.
- **VAN 152** — 하드웨어 ID(HWID) 밴 조치로 이 기기에서 게임을 할 수 없다는 뜻입니다. **재설치·재부팅·연결 설정 변경으로는 풀리지 않고** 상담원 문의로만 진행됩니다.
- **VAN -81** — 뱅가드가 시작, 연결 유지, 준비 상태 확인에 문제를 겪고 있다는 뜻입니다. PC 재시작 → Windows 날짜·시간·시간대 확인 → vgc 자동 시작 → 뱅가드 재설치 → 클린 부팅 순서로 해봅니다.

## 재설치해도 안 되면 — 충돌하는 프로그램 찾기

### 라이엇이 이름을 적은 프로그램, Fasoo

VAN 84 문서는 프로그램 이름을 적지 않지만, 리그 오브 레전드 **VAN 83** 문서에는 구체적인 이름이 나옵니다.

> 뱅가드 설치가 되지 않는다면 다른 보안 프로그램과 충돌할 수 있습니다.
> Fasoo 소프트웨어에 책임이 있을 수 있습니다. 이 소프트웨어를 제거하여 문제를 해결할 수 있습니다.

Fasoo(파수)는 문서 보안(DRM) 프로그램입니다.

### 앱 목록에서 게시자 확인

라이엇이 안내하는 제거 방법은 이렇습니다.

1. 제어판 → **프로그램 및 기능**
2. 게시자가 `fasoo.com` 인 항목을 찾아 설치 해제
3. PC 재시작

### 앱 목록에 안 보이면 — 실행 중인 드라이버 조회

앱 목록이나 트레이에 아무것도 없어도 드라이버는 돌고 있을 수 있습니다. 아래 명령은 **PowerShell** 에서 실행합니다(명령 프롬프트 cmd에서는 동작하지 않습니다). 지금 실행 중인 드라이버 가운데 Microsoft가 아닌 것만 회사명과 함께 보여줍니다.

<CopyableCode code={String.raw`Get-CimInstance Win32_SystemDriver | Where-Object { $_.State -eq 'Running' -and $_.PathName } | ForEach-Object { $p = $_.PathName -replace '^\\\?\?\\','' -replace '^\\SystemRoot','C:\Windows' -replace '^System32','C:\Windows\System32'; $c = (Get-Item $p -ErrorAction SilentlyContinue).VersionInfo.CompanyName; if ($c -notmatch 'Microsoft') { [pscustomobject]@{Name=$_.Name; Company=$c; Path=$p} } } | Format-Table -AutoSize`} />

결과에는 Intel·NVIDIA·Realtek·ELAN 같은 정상적인 하드웨어 드라이버도 함께 나오고, 회사명이 비어 있는 항목도 있습니다. 여기서 볼 것은 파수 드라이버입니다. 파수 공식 기술 문서에 드라이버로 나열된 파일은 다음 세 개입니다.

- `f_ih.sys`
- `f_npm.sys`
- `f_protflt.sys`

모두 `C:\Windows\System32\drivers` 에 있습니다. 설치 폴더는 `C:\Program Files\Fasoo DRM`, `C:\Program Files\Fasoo` 같은 이름입니다.

최근에 생긴 드라이버를 생성일 순으로 보는 방법도 있습니다.

<CopyableCode code={String.raw`Get-ChildItem C:\Windows\System32\drivers\*.sys | Sort-Object CreationTime -Descending | Select-Object -First 15 Name, CreationTime`} />

다만 이 목록 맨 위에는 최근 Windows 업데이트로 생긴 **Microsoft 드라이버가 섞여 나옵니다.** 생성일이 최근이라는 이유만으로 문제 파일이 되는 것은 아니니, 이 목록을 지울 파일 목록으로 보면 안 됩니다.

오류 창에 "VAN: Incompatible Software"처럼 호환되지 않는 소프트웨어와 파일 경로가 표시됐다면, 그 경로를 기록해 두고 연결된 프로그램을 앱 목록에서 제거한 뒤 재시작하는 것이 라이엇 안내 순서입니다.

## 파수 DRM이 제거되지 않을 때 — 실제 해결 사례

라이엇이 안내한 방법은 게시자 `fasoo.com` 항목을 앱 목록에서 제거하는 것입니다. 그 방법이 막혔을 때 이런 식으로 해결한 사례도 있습니다.

### 해결까지의 과정

개인 노트북(Windows 10)에서 롤을 켜자 VAN 84가 떴습니다. 뱅가드를 재설치해도 업데이트가 끝나지 않았고, 트레이 아이콘과 설치된 앱 목록에서는 의심 가는 프로그램이 보이지 않았습니다.

1. 위의 PowerShell 명령으로 실행 중인 드라이버를 조회하자 `f_ih.sys`, `f_npm.sys` 가 나왔습니다. 업무 문서를 열면서 깔린 것으로 보였습니다.
2. 시작 프로그램 관리 도구인 Autoruns에서 체크를 해제했지만, 재부팅하면 다시 체크돼 있었습니다.
3. `C:\Program Files\Fasoo DRM` 폴더에는 언인스톨 파일이 없었습니다.
4. 안전 모드로 부팅해 파일 이름을 바꾸려 했지만 액세스가 거부됐습니다.
5. **Windows 복구 환경의 명령 프롬프트** 에서는 이름 변경이 됐고, 이후 롤이 정상 실행됐습니다.

### 1. 복구 환경에서 명령 프롬프트 열기

- **Shift** 키를 누른 채 전원 → **다시 시작**
- 또는 설정의 **복구** 화면 → 고급 시작 옆 **지금 다시 시작**

파란 화면이 나오면 **문제 해결 → 고급 옵션 → 명령 프롬프트** 를 선택합니다. Windows 10은 이때 관리자 계정의 암호를 묻습니다.

### 2. Windows가 있는 드라이브 문자 확인

복구 환경에서는 평소 C: 이던 드라이브가 다른 문자로 보일 수 있습니다. 먼저 Windows 폴더가 어디 있는지 확인합니다.

```
dir C:\Windows
```

Windows 폴더 내용이 나오지 않으면 D: 로 확인합니다.

```
dir D:\Windows
```

아래 명령으로도 확인할 수 있습니다. 출력에 `osdevice partition=D:` 처럼 나오면 D: 입니다.

```
bcdedit | find "osdevice"
```

### 3. 드라이버와 폴더 이름 바꾸기

사례 PC의 조회 결과에 나온 것은 `f_ih.sys`·`f_npm.sys` 두 개였고, 폴더는 `C:\Program Files\Fasoo DRM` 이었습니다. 아래 명령은 그 PC 기준이고, 드라이브는 D: 로 보였습니다. **D: 부분은 위에서 확인한 드라이브 문자로 바꿔서** 입력합니다.

<CopyableCode code={String.raw`ren D:\Windows\System32\drivers\f_ih.sys f_ih.sys.bak
ren D:\Windows\System32\drivers\f_npm.sys f_npm.sys.bak
ren "D:\Program Files\Fasoo DRM" "Fasoo DRM_bak"`} />

지우지 않고 이름 끝에 `.bak` 을 붙이는 방식이라, 문제가 생기면 이름을 원래대로 돌려놓을 수 있습니다.

### 4. 일반 부팅 후 롤 실행

명령 프롬프트를 닫고 PC를 다시 시작해 평소처럼 Windows로 부팅합니다. 사례 PC에서는 롤을 실행하자 **"뱅가드 세션을 초기화하는 중"** 화면을 거쳐 게임이 정상적으로 실행됐고, 이후로도 계속 정상 플레이됐습니다.

이 화면에서 멈춰 넘어가지 않았을 때는 재부팅을 한 번 더 하자 해결됐습니다.

## 되돌리는 방법

파수가 다시 필요해지면 같은 복구 환경 명령 프롬프트에서 이름을 반대로 바꿉니다. 여기서도 D: 는 그 PC에서 확인한 드라이브 문자로 바꿉니다.

<CopyableCode code={String.raw`ren D:\Windows\System32\drivers\f_ih.sys.bak f_ih.sys
ren D:\Windows\System32\drivers\f_npm.sys.bak f_npm.sys
ren "D:\Program Files\Fasoo DRM_bak" "Fasoo DRM"`} />

## 자주 묻는 질문

### VAN 84는 무슨 뜻인가요?

라이엇 뱅가드가 PC가 게임을 실행할 준비가 됐는지 확인하지 못했거나, 초기화 중에 문제가 생겼다는 뜻입니다.

### vgc 서비스를 꼭 자동으로 바꿔야 하나요?

사전 검사(Pre-Check)를 쓰지 않는 PC라면 자동으로 설정하라는 것이 라이엇 공식 안내입니다. Pre-Check는 Windows 11 25H2 이상, 보안 부팅, TPM 2.0 등 6가지 조건을 모두 갖춰야 쓸 수 있어서 Windows 10에서는 사용할 수 없습니다.

### 파수 DRM이 정말 뱅가드와 충돌하나요?

라이엇의 리그 오브 레전드 VAN 83 문서가 Fasoo 소프트웨어를 원인 후보로 직접 적고, 제어판에서 게시자가 `fasoo.com` 인 항목을 제거하라고 안내합니다.

### VAN 152는 재설치하면 풀리나요?

풀리지 않습니다. 하드웨어 ID(HWID) 밴 조치라 재설치·재부팅·연결 설정 변경으로는 해결되지 않고, 상담원 문의로만 진행됩니다.

### 복구 환경 명령 프롬프트가 암호를 물어요

Windows 10은 관리자 권한이 있는 로컬 계정의 이름과 암호를 묻습니다. 평소 Windows에 로그인할 때 쓰는 계정 암호를 넣으면 됩니다.
