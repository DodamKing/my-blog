# GA4 첫 전수 분석 + 10-29 급등 원인 조사 (2026-10-31)

GA4 Data API 연결 첫날 분석이다(셋업: [`../setup/ga4-api.md`](../setup/ga4-api.md)). 서치 어드바이저 TOP30(클릭 있는 상위 30개만, 30일 합계)과 달리 **219편 전부를 날짜별로** 본다. 데이터는 2026-01 부터 있다.

⚠️ 지표는 **GA4 페이지뷰**다. 서치 어드바이저 클릭과 단위가 다르고 조금 적게 나온다.
분석 스크립트: 스크래치 `analyze.cjs` (재사용할 부분은 `npm run traffic` 에 이미 있음)

## 1. 10-29 급등 — 사이트 전체가 네이버에서 한 번에 올랐다

| 근거 | 값 |
|---|---|
| 사이트 일평균 PV (10-15~28 → 10-29~30) | 58 → 190 |
| 네이버 모바일 검색 유입 | 33.7 → **136.0** /일 |
| 네이버 PC | 4.6 → 24.0 |
| Bing · 직접 | 7.2 → 10.5 · 9.1 → 9.5 (거의 그대로) |
| **글별 배수** (기준 일평균 0.5↑ 36편) | **중앙값 2.3배 · 2배↑ 25편 · 1배 미만 3편** |
| 레딜식 새 3편 (10-25) | 0~1 /일 — 급등과 무관 |
| 우리 쪽 변경 | 없음 (마지막 커밋 10-25) |

**한 편이 아니라 거의 모든 글이 비슷한 배수로 올랐다** → 글 단위가 아니라 **네이버가 우리 도메인을 보여주는 방식**이 바뀐 것이다.

### 원인 — 미확인

- 네이버 공식 발표는 찾지 못했다(웹 검색 · 서치어드바이저 공지는 fetch 차단). 10-15 파워컨텐츠 광고 UX 개편 보도만 있다
- 모바일 통합검색 실측(`썸원 반려몽 종류`): 블로그·지식iN·외부 웹사이트가 **칸 구분 없이 한 목록**에 섞여 나오고 우리 글은 1페이지 하단. 이 배치가 언제부터인지는 비교 자료가 없어 모른다
- ⛔ 원인을 추측으로 확정하지 않는다. **유지되는지**(1주 추적)와 **서치 어드바이저 최근 7일 키워드**가 다음 근거다

## 2. 1면 진입 ≠ 트래픽

| 글 | 1면 | GA4 PV |
|---|---|---|
| 아모스 (흡수 3편) | 기록 질문 **8/17** · 타겟 1위 | 발행 30일 **9** |
| 김치냉장고보상판매 | 4위 | 10-15 이후 **1** |
| 메디올 · 쿠쿠 네모 | 9위 · 5위 | 2 · 4 |

1면에 들어도 **그 검색어를 치는 사람이 적으면** 트래픽이 없다. 반대로 급등의 수혜는 **이미 수요가 있는 오래된 글**(썸원·레딜·노트북·쿠쿠 서비스센터)이 가져갔다.
