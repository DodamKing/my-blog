## 왜 이 실험이 필요한가

2026-09-20 스냅샷에서 **08-27~09-18 발행 11편이 웹문서 TOP30 에 한 편도 없었다.** 전부 8클릭 이하 = 합계가 총량의 8% 미만이다. 한 달 발행 노동이 순증을 거의 못 만들었다.

같은 스냅샷에서 반대 방향의 숫자가 나왔다:

| 관측 | 값 |
|---|---|
| 노출 10~50 구간 CTR (TOP30 전수) | **25.0%** |
| 노출 51~200 | 6.3% |
| 노출 201~900 | 1.6% |
| H5 흡수 배수 (상위 자산이 목록 밖 꼬리에서 받는 비율) | 예초기 **4.6배** · 레딜 2.6배 · 썸원 2.3배 |
| 우리형 슬롯이 1면에 차지하는 자리 (Q4) | 평균 **1.4개 이하** |

→ **작은 자리를 여러 개 먹는 쪽이 큰 자리 하나를 노리는 것보다 기대값이 높다**는 계산이 나왔다.

## 부록 — `npm run harvest` 양성 대조군 시험 (2026-09-21)

흡수 질문을 어디서 모을지 자동화하려고 만든 도구를 **쓰기 전에 아는 답으로 시험했다** (09-20 에 `serp-audit` 을 playwright 로 7/7 대조한 것과 같은 방식).

### 시험 1 — 증상어 역검색으로 우리 승리 자산이 나오나 → ⛔ **실패**

`목아픔`·`가래`·`교환방법`·`부품교체`·`내돈내산` × 3페이지 = **150건** 수집.

| | 결과 |
|---|---|
| 직격 히트 | **1건** — `전자담배 목아픔` (브랜드가 아니다) |
| 예초기 | **0건** |
| 아큐스터 | **0건** |

실제로 나온 것: `목아픔`→"웃으면 목아픔"·"인후염?" / `교환방법`→타오바오·번개장터 / `내돈내산`→"리뷰 명예훼손 고소"

### 시험 2 — 그럼 지식iN 에 그 제품 얘기가 없나 → ✅ **아주 많다**

```
레딜     10/10   "레딜 제로 가성비 괜찮을까요?" · "레딜 니코틴 검사에 안 걸리나요?"
예초기   10/10   "예초기에 경유 혼유" · "예초기 사고 후 바로 응급실"
아큐스터   1+    "허리디스크 있는데 아큐스터 괜찮나요?"
```

### 진단 — 물은 있고 두레박이 잘못됐다

**증상어가 흔할수록 제품이 노이즈에 묻힌다.** 목 아픈 사람은 수만 명이고 레딜 쓰는 사람은 극소수라 상위 30건에 못 든다. **레딜은 사람들이 *검색한* 말이지 지식iN 에 *물어본* 말이 아니었다.**

`에러코드` 가 잘 됐던 이유도 같은 원리다 — **기계만 내는 말이라 제품 없이는 성립이 안 된다**(10건 중 7건이 브랜드).

→ **도구의 자리를 옮겼다: 시드 발굴기 → 흡수 가능성 측정기.** 시드는 추천기·판정 완료 큐가 계속 공급하고, harvest 는 **후보의 질문 개수를 발행 전에 수 초에 재는** 데 쓴다.

### ⭐ 그리고 전제 하나가 정정됐다

**09-21 발행 0 의 원인은 시드 공급이 아니었다.** 오쏘몰(쇼핑 SERP)·갤럭시워치9(형태)·샤워기헤드(규모) 세 건 다 **시드는 추천기에서 멀쩡히 왔고 게이트에서 죽었다.** 시드 자동화를 더 파는 것은 잘못된 문제를 푸는 것이었다.
