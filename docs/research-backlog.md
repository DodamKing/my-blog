## ⚡ 판정 완료 큐 — 바로 꺼내 쓰는 후보

`/api/judge` 판정을 이미 받았으나 아직 발행하지 않은 키워드. **"오늘의 키워드"에 쓸 만한 게 없을 때, 또는 주말처럼 시드 스캔 없이 바로 쓰고 싶을 때 여기서 꺼낸다.** 판정 비용을 이미 지불한 자산이므로 judge를 다시 부르지 않는다.

⚠️ **판정 유효기간 3개월.** 판정일로부터 3개월이 지난 후보는 SERP가 바뀌었을 수 있으니 꺼내기 전 judge 1회만 재확인한다.

### 🌱 미확장 시드 (스캔 대기)

CLAUDE.md "뚫리는 시드 유형 — 자체 A/S망을 가진 국내 가전 브랜드" 근거. 쿠쿠가 판정 5개 전부 ✅로 열린 성격과 같은 후보군이다. 쓸 거리가 떨어지면 `npm run scan -- <시드>` 를 여기서 하나씩 꺼내 돌린다.

**쿠첸 · 위닉스 · 신일 · 코웨이 · SK매직 · 청호나이스 · 위니아 · 캐리어**

- ⚠️ **위니아를 확장할 때 김치냉장고 축은 건너뛴다** (2026-07-30). 김치냉장고 시드 80개를 이미 확장했고 결과는 아래와 같다. 위니아=딤채라 그대로 겹친다. **서비스센터·에어컨·제습기 등 다른 제품군 축으로 확장할 것**
  - 문제해결 축은 **광고가 1~3개뿐이라 자리는 열려 있다**(광고주 미입찰 = 순수 정보 검색). 막은 건 볼륨과 문서 벽이다 — `김치냉장고온도` 2,400인데 문서 143,832(기대클릭 72), `딤채 김치냉장고 고장` 문서 3,682로 얇지만 볼륨 540(기대클릭 43), `김치냉장고 물샘` 320(26). 전부 발행 하한 100 미달
  - 스펙·브랜드·가격 축 약 70개는 노출광고수 8~10 + 문서 수만~수십만으로 쇼핑탭 영역
  - 건진 것은 `김치냉장고보상판매` 1개뿐 (기대클릭 274)
  - ⚠️ **쿠쿠 클러스터도 초저볼륨이었다**(문서 25건 축). 새 발행 하한을 소급 적용하면 통과 못 했을 수 있다 — **8/11 쿠쿠 측정이 하한 수치 자체의 검증**이 된다. 결과를 보고 CTR 계수를 보정할 것
- 한 번에 1~2개만. 10개 동시 확장 금지 (네이버 무료 쿼터 공유)
- 확장 후 결과는 이 문서의 ✅/△/⛔ 표로 흡수시켜 다음 세션이 재사용할 수 있게 한다

3편 모두 2026-07-05 발행. 쿠팡 딥링크는 뉴트리코스트만 자동 매칭 성공, SAN 퍼포먼스는 브랜드 불일치로 수동 확인 필요 상태로 남음. 다음 측정 사이클에서 3편 각각의 노출·클릭을 분리 추적 — 패턴별 분리 발행이 총정리 브로드 가이드보다 나은지 확인하는 실험 표본이기도 하다.
